step by step.

Use Google Sheets for a live connection today. Excel can hold exported records, but direct Excel or Microsoft 365 synchronisation is not connected yet.

Google Sheets · live connection

  1. Create a new Sheet. In your own Google Drive, create a blank Google spreadsheet and name it “My practice accounts”. Do not share it publicly.

  2. Copy its ID. In the spreadsheet URL, copy the text between /d/ and /edit.

  3. Open Apps Script. In the Sheet, choose Extensions → Apps Script. Replace the sample code with this backend script.

  4. Add three Script properties. Open Apps Script → Project Settings → Script properties. Add SPREADSHEET_ID with your Sheet ID; SHARED_SECRET with a unique, random secret of at least 32 characters; and ALLOWED_EMAILS with the exact email shown on your LexChamber setup page. Keep the secret private. It is not your Google password.

  5. Create your tabs. Save the script. Select setupNewPractice in the function menu and click Run. Review and authorise the requested Google Sheets/Drive permissions. This creates the Clients, Cases, Invoices and Transactions tabs and the supporting registers. The script backs up before schema changes.

  6. Publish the connection. Choose Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone. Deploy, then copy the web app URL ending in /exec. The endpoint is reachable, but every data request requires the secret-signed message and approved email. Your spreadsheet itself remains private.

  7. Connect LexChamber. Return to your setup page. Choose Starter or Pro, choose monthly or annual billing, paste the web app URL and enter the same shared secret. Click “Verify backend and activate trial”. Your seven days start only after verification succeeds.

  8. Check your particulars. Open Settings and enter your own practice name, contact information, bank details, rates and VAT particulars. Review these before issuing any invoice.

If the connection fails

Check that the email matches your verified primary Clerk email, the two secrets match, the URL ends in /exec, and the Sheet ID is correct. If you changed script code, use Deploy → Manage deployments → Edit → New version → Deploy. Saving code alone does not update the deployed web app.

Excel · exports and preparation

  1. Keep your workbook in your own OneDrive, SharePoint or local storage. Make a backup before changing it.

  2. Use separate worksheets for Clients, Cases, Invoices, Payments and Transactions. Keep IDs as text, one header row and one record per row; avoid merged cells in data tables.

  3. LexChamber CSV exports can be opened in Excel using Data → From Text/CSV. Check date formats, decimal separators and that account numbers and IDs remain text.

  4. Editing an exported workbook does not update LexChamber. Excel uploads are not a live backend connection. For a working trial now, connect Google Sheets. Contact info@lexchamber.co.za if you require a Microsoft 365 integration.

Your control and backups

You own and administer the Sheet. Keep regular copies, restrict Google account access and review permissions. You can disable the Apps Script deployment or change its shared secret to revoke the connection. Disabling the connection stops the app from accessing your records; it does not delete the Sheet. Clerk stores your account and private connection settings; the app server processes records to provide the service.
