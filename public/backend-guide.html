You will create a private spreadsheet, add the supplied connection code and paste two details into LexChamber. You do not need to write any code.

Already connected? Update your existing setup instead.
  1. Make a backup of your existing Sheet.
  2. Open its existing Apps Script project. Replace the contents of Code.gs with the code in step 2 below.
  3. Keep your existing SPREADSHEET_ID, SHARED_SECRET and ALLOWED_EMAILS properties. If SPREADSHEET_ID is missing, add the ID of your existing practice Sheet.
  4. Choose Deploy → Manage deployments → Edit (pencil) → New version → Deploy.
  5. Return to LexChamber and select Refresh.

Keep the same deployment URL. You do not need a new spreadsheet, a new connection or another trial. Do not repeat the new-practice steps below.

STEP 1 OF 6

Create your private spreadsheet.

  1. In Google Drive, choose New → Google Sheets → Blank spreadsheet.
  2. Name it My practice accounts. Keep its sharing set to Restricted.
  3. Copy the spreadsheet ID from its address bar.

Example: docs.google.com/spreadsheets/d/THIS_IS_THE_ID/edit

Copy only the part between /d/ and /edit. This is the spreadsheet ID, not an Apps Script ID or a Google Drive folder ID.

STEP 3 OF 6

Add three connection settings.

In Apps Script, click the Project Settings ⚙ icon on the left. Scroll to Script properties → Add script property.

Add all three rows below. Copy the property names exactly, including the capital letters, then click Save script properties.

PropertyValue to enter
SPREADSHEET_IDThe spreadsheet ID you copied in step 1.
SHARED_SECRETA private connection password. Generate one below and paste it here. Keep a copy for step 6.
ALLOWED_EMAILSYour verified LexChamber account email—the exact email shown on your setup page.

This password connects LexChamber to your Sheet. It is not your Google password or an AI API key. It is generated on this device and is not saved by this guide. Keep it private.

STEP 4 OF 6

Create the practice tabs.

  1. Click Editor < > on the left to return to Code.gs.
  2. At the top, select setupNewPractice from the function dropdown.
  3. Click Run. Choose your Google account and review the requested Sheets and Drive permissions.
  4. When Google shows Execution completed, return to your Sheet. The practice tabs should now be present.

If Google asks for authorisation, authorise only the project you created with the supplied code. If your organisation blocks it, ask your Google administrator for help.

STEP 5 OF 6

Deploy the connection.

  1. In Apps Script, choose Deploy → New deployment.
  2. Click the gear beside “Select type” and choose Web app.
  3. Set Execute as to Me.
  4. Set Who has access to Anyone, then click Deploy.
  5. Copy the Web app URL ending in /exec.

“Anyone” applies to the connection endpoint, not your spreadsheet sharing. Your Sheet stays Restricted. The code requires signed requests and your approved email before returning or changing records.

If “Anyone” is unavailable, your Google Workspace administrator may need to permit this deployment.

STEP 6 OF 6

Connect and check LexChamber.

  1. Return to your LexChamber setup page.
  2. Choose monthly or annual billing.
  3. Paste the Web app URL from step 5 and the same shared secret from step 3.
  4. Click Verify connection and start trial.
  5. Once connected, open Settings. Add and check your practice name, contact details, bank details, rates and VAT particulars before issuing invoices.

Your seven-day trial starts after the connection is verified. No payment is taken during setup.

Something not working?

“Set SPREADSHEET_ID” or the spreadsheet cannot be found

Return to step 3. Check that SPREADSHEET_ID exists and contains only the correct Sheet ID. Use the Google account that owns or can edit that Sheet.

Connection verification fails

Check the three most common causes: the shared secret must match exactly; ALLOWED_EMAILS must match your verified LexChamber email; and the Web app URL must end in /exec. Confirm Execute as: Me and Who has access: Anyone.

I changed the code, but nothing changed in LexChamber

Saving the code does not update its deployment. Choose Deploy → Manage deployments → Edit → New version → Deploy, then refresh LexChamber. Keep the existing URL.

I cannot find setupNewPractice

Check that all the supplied code was pasted into Code.gs and saved. Then open the function dropdown again.

Can I use Excel instead?

Excel can open exported CSV files, but live Excel synchronisation is not supported. Use Google Sheets for the live connection.

Need help? Email info@lexchamber.co.za with the error message or a screenshot. Hide connection passwords, keys and confidential practice records.

Keep regular backups of your Sheet. You control its records and permissions. Disabling the Apps Script deployment stops the connection without deleting your spreadsheet.
